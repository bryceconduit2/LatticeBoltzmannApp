# Fluid Sandbox

**Lattice Boltzmann CFD Sandbox** is an interactive 2D fluid dynamics wind tunnel right on your mobile device. It allows you to simulate airflow, test aerodynamic shapes, and analyze fluid physics in an intuitive, hands-on environment.

---

## Key Features

* **Interactive Wind Tunnel:** Draw custom obstacles (circles, squares) or load preset NACA airfoil profiles.
* **Aerodynamic Analysis:** Adjust Angle of Attack (AoA), airflow speed, fluid viscosity, and density while tracking live Force (N) and Lift/Drag coefficients.
* **Visualizations:** Toggle between Velocity, Static Pressure, and Total Pressure contour maps with multiple color schemes (Jet, Heat, Grayscale, Ocean).
* **Physics Engine:** Built using WALE subgrid-scale turbulence modeling, BFL interpolated boundaries, and momentum exchange force integration.
* **Performance & Customization:** Tweak grid resolution, physics precision (dt), and multi-core CPU usage for maximum frame rate.

---

## Privacy & Offline Operation

* **100% Offline:** No ads, no tracking, no data collection. All calculations run entirely on your local device.
